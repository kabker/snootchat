# SnootChat

make me a chat platform where you can chat. when signing up, you can sign up using email or google. you also have to create a username, display name, and password. they can also upload a profile picture or use the default pfp which is their display name's initials. its called SnootChat. when you want to chat someone, you need to send a request to them to chat. you can choose from 8 different chat backgrounds, or upload your own and both (or all) people can see it. you can also add people to group chats, but they need to accept it before they can read messages or send them. add delivered and sent indicators. make the sender message bubbles customizable as well but that is only for the sender on every chat. the message bubble colors are, blue, purple, black, white. the received message bubbles from the other sender are gray.
